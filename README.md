# Space Tourism Website

A responsive multi-page HTML/CSS/JavaScript implementation inspired by the supplied reference screenshot.

## Files
- `index.html` — home page
- `destination-moon.html`, `destination-mars.html`, `destination-europa.html`, `destination-titan.html`
- `crew-commander.html`, `crew-engineer.html`, `crew-pilot.html`, `crew-specialist.html`
- `technology-vehicle.html`, `technology-spaceport.html`, `technology-capsule.html`
- `css/style.css` — shared responsive styles
- `js/script.js` — mobile navigation menu

## Add your assets
Copy your existing asset files into the matching folders under `assets/`:
- `assets/home/background-home-desktop.jpg`
- `assets/destination/background-destination-desktop.jpg` and the `image-moon`, `image-mars`, `image-europa`, `image-titan` `.webp` and/or `.png` files
- `assets/crew/background-crew-desktop.jpg` and the crew portrait files
- `assets/technology/background-technology-desktop.jpg` and the technology portrait/landscape files
- `assets/shared/logo.svg`, `icon-hamburger.svg`, `icon-close.svg`

The HTML uses the filenames you listed. If your project already has these assets in a different directory, either move them into these folders or update the paths in the HTML/CSS.

## Run it
Open `index.html` in a browser. No build step is required. For best results, use VS Code with the Live Server extension.
